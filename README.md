# dotfiles

Personal macOS & Linux dotfiles managed with [chezmoi](https://chezmoi.io).

## Stack

| Layer | Tool |
|---|---|
| Dotfiles manager | chezmoi |
| Shell | Zsh + Starship prompt |
| Terminal | Ghostty |
| Editor | Helix · VS Code · Zed |
| Packages | Homebrew (Brewfile) |
| Runtimes | mise (Python · Node · Go · Rust · Java) |
| SSH config | `~/.ssh/config` + `~/.ssh/config.local` |

## Install

```sh
sh -c "$(curl -fsLS https://raw.githubusercontent.com/akrisanov/dotfiles/master/bootstrap.sh)"
```

The script will:

1. Install Homebrew (if missing)
2. Install chezmoi and run `chezmoi init --apply`

On first run chezmoi will prompt for **name**, **email** and **SSH signing key** — saved to `~/.config/chezmoi/chezmoi.toml`.

The SSH signing key is your existing public key, e.g.:

```sh
cat ~/.ssh/id_ed25519.pub
# paste the full line: ssh-ed25519 AAAAC3Nza...
```

## Local development (existing machine)

If the repo is already cloned locally:

```sh
mkdir -p ~/.local/share
ln -sf ~/Projects/dotfiles ~/.local/share/chezmoi
chezmoi init          # generates ~/.config/chezmoi/chezmoi.toml
chezmoi diff          # preview changes
chezmoi apply         # apply dotfiles
```

## Update

```sh
chezmoi update   # pull + apply
chezmoi apply    # apply local changes only
```

## Packages

```sh
brew bundle --file=~/Brewfile      # install everything
brew bundle check --file=~/Brewfile # show what's missing
brew bundle cleanup --file=~/Brewfile # remove packages not in Brewfile
```

> `~/Brewfile` is generated by chezmoi from `Brewfile.tmpl`. Hardware-specific apps
> (`tg-pro`, `monitorcontrol`, `betterdisplay`, `fontsmoothingadjuster`) are skipped on MacBook Air.

## macOS defaults

```sh
~/dotfiles/scripts/osx-tweaks
```

## Git profiles

Profiles auto-activate by directory:

| Directory | Profile |
|---|---|
| `~/Projects/` | `~/.config/git/profiles/personal.gitconfig` |
| `~/Work/` | `~/.config/git/profiles/work.gitconfig` |

Copy an example and fill in your details:

```sh
cp ~/.config/git/profiles/personal.gitconfig.example ~/.config/git/profiles/personal.gitconfig
```

Or switch manually:

```sh
gitprofile personal
gitprofile          # show current
```
