# Wallpapers

Place your wallpapers here:

- `dark.jpeg` — used when macOS is in **Dark Mode**
- `light.jpg` — used when macOS is in **Light Mode**

The `wallpaper-switch.sh` script reads these files automatically
when triggered by the `com.akrisanov.wallpaper` LaunchAgent.

These image files are intentionally not committed to the dotfiles repository.
